# INTEGER — a daily mathematical deduction game

Find the hidden positive integer from number-theory clues. Every guess lights up the clues *that guess* satisfies — nothing stays lit from earlier guesses. One shared puzzle per day, changing at midnight America/New_York.

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest
npm run build      # type-check + production build into dist/
npm run preview
```

## Deploy
**Vercel:** import the repo (Framework preset: Vite; build `npm run build`; output `dist`). Or `npx vercel --prod`.
Any static host works (Netlify, GitHub Pages, Cloudflare Pages): serve `dist/`.

## Architecture
| Path | Purpose |
|---|---|
| `src/engine/math.ts` | Factorization, d(n), σ(n), φ(n), primes, powers, digits, triangular/Fibonacci, modular helpers |
| `src/engine/clues.ts` | Clue registry: parametrised clue ids (`div:7`, `mod:5:2`, `tau:6`, …) → text, category, difficulty, evaluator, explanation |
| `src/engine/validate.ts` | Exhaustive solver; puzzle must have exactly one solution and no redundant clue |
| `src/engine/dates.ts` | New York calendar-day keys, DST-safe day arithmetic, countdown |
| `src/puzzles/data.ts` | Curated pool (46 puzzles: 10 easy, 26 medium, 10 hard), generated by `scripts/generate-puzzles.ts` and re-verified by tests |
| `src/puzzles/daily.ts` | Deterministic, seeded daily selection (Medium daily; every 7th day a Hard/Easy special) |
| `src/game/*` | Guess validation, win detection, statistics (derived from history), LocalStorage persistence, share text |
| `src/components/*`, `src/App.tsx` | UI |

**Adding puzzles:** `npm run generate` prints candidates; `-- --write` rewrites `data.ts`. Never renumber ids once published — append only (changing the pool changes future days' selections).

**Design notes:** stats are computed from per-day records, so a solved day can't be replayed or overwritten (even by a stale second tab), and storage events keep tabs in sync.
